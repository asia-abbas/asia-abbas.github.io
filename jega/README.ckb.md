# جێگا · Jêga

ئەپی بەکرێدانی جێگای ئۆتۆمبێل بۆ هەولێر و هەموو شارەکانی عێراق. شۆفێر جێگا دەدۆزێتەوە و حیجزی دەکات، خاوەن جێگاش بەردەم ماڵ، گەراج یان شوێنی خۆی لە هەر ناوچەیەک دادەنێت و پارەی لێ پەیدا دەکات.

**ڕێنمایی ئینگلیزی و وردەکاری تەواو:** [README.md](README.md)

## بەشەکان

| بەش | فۆڵدەر | بۆ کێ | چوونەژوورەوە |
|---|---|---|---|
| ئەپی جێگا (PWA) | `app/` | شۆفێر و خاوەن جێگا | تەنها ژمارەی مۆبایل، بێ کۆد |
| داشبۆردی بەڕێوەبەر (ماڵپەڕی جیا) | `admin/` | تەنها خاوەنی ئەپ | ئیمەیڵ و وشەی نهێنی |
| باکئێند | `functions/` | — | — |

## تایبەتمەندییەکان

- چوار زمان: ئینگلیزی، عەرەبی، کوردی سۆرانی، کوردی بادینی. عەرەبی و هەردوو زاراوەی کوردی لە ڕاستەوە بۆ چەپ دەنووسرێن.
- نەخشە (OpenStreetMap) و لیست، گەڕان، فلتەری ناوچە و «نزیک من».
- دوو شێوازی نرخ: **بە کاتژمێر** (نرخ × کاتژمێر) یان **نرخی جێگیر** (هەمان نرخ بۆ هەر ماوەیەک).
- پارەدان: **کاش لە کاتی گەیشتن** یان **ئۆنلاین لە ڕێگەی FuratPay** (FIB، کی کارد، FastPay و هتد).
- گفتوگۆ لە نێوان شۆفێر و خاوەن جێگا.
- ئاگادارکردنەوە: لیستی ناو ئەپ، ئاگادارکردنەوەی خێرا، و ئاگادارکردنەوەی مۆبایل کاتێک ئەپەکە داخراوە.
- بیرخستنەوە ٣٠ خولەک پێش دەستپێک و ١٥ خولەک پێش کۆتایی.
- داشبۆردی بەڕێوەبەر: ئامار، نەخشەی هەموو جێگاکان، ئاگادارکردنەوەکان، حیجزەکان، ڕاگرتنی جێگا، بلۆککردنی بەکارهێنەر، پارەدانەکان، ناردنی ئاگادارکردنەوە بۆ هەمووان، و ڕێکخستنی ڕێژەی کرێ.

## دامەزراندن (نزیکەی ٣٠ خولەک)

پێویستیت بە ئەکاونتی گووگڵ، [Node.js 20](https://nodejs.org) و `npm i -g firebase-tools` هەیە.

١. لە [console.firebase.google.com](https://console.firebase.google.com) پرۆژەیەک دروست بکە و بیگۆڕە بۆ پلانی **Blaze**.

٢. ئەم خزمەتگوزارییانە چالاک بکە:
   - **Firestore Database**
   - **Authentication → Email/Password** (تەنها بۆ بەڕێوەبەر)
   - **Add app → Web** و ڕێکخستنەکان کۆپی بکە
   - **Cloud Messaging → Web Push certificates → Generate key pair**

٣. ڕێکخستنەکان دابنێ:
   - `app/js/firebase-config.js` و `admin/js/firebase-config.js`: ڕێکخستنی وێب (هەمان نرخ لە هەردووکیان)
   - `VAPID_KEY` لە `app/js/config.js` و `admin/js/admin.js`
   - لە `.firebaserc` و `functions/.env` وشەی `your-project-id` بگۆڕە بۆ ناسنامەی پرۆژەکەت

٤. لە Hosting ماڵپەڕێکی دووەم دروست بکە بۆ داشبۆرد، وەک `your-project-id-admin`.

٥. نهێنییەکانی پارەدان دابنێ. تا ئەکاونتی FuratPay ت نییە، بۆ هەردووکیان `none` بنووسە:

<div dir="ltr">

```bash
firebase login
firebase functions:secrets:set FURATPAY_API_KEY
firebase functions:secrets:set FURATPAY_WEBHOOK_SECRET
cd functions && npm install && cd ..
firebase deploy
```

</div>

٦. ئەکاونتی بەڕێوەبەر دروست بکە. لە Project settings → Service accounts کلیلێک دابگرە و بە ناوی `functions/service-account.json` پاشەکەوتی بکە. ئەم فایلە لای کەس دامەنێ. پاشان:

<div dir="ltr">

```bash
cd functions
node scripts/make-admin.mjs you@example.com "وشەی-نهێنیی-بەهێز"
```

</div>

## FuratPay

ئێستا لە **دۆخی تاقیکردنەوە** دایە. شۆفێر پەڕەیەکی تاقیکردنەوە دەبینێت کە دوگمەی «Pay» و «Decline»ی تێدایە، و هیچ پارەیەکی ڕاستەقینە نابڕدرێت.

کاتێک ئەکاونتی بازرگانیت لە FuratPay وەرگرت:

١. لە داشبۆردی FuratPay ئەمانە کۆپی بکە: **API key** و **Webhook secret**.

٢. دایانبنێ:

<div dir="ltr">

```bash
firebase functions:secrets:set FURATPAY_API_KEY
firebase functions:secrets:set FURATPAY_WEBHOOK_SECRET
firebase deploy --only functions
```

</div>

٣. لە داشبۆردی FuratPay، Webhook URL دابنێ. ئەم بەستەرە لە داشبۆردی بەڕێوەبەر → Settings دەبینیت.

٤. پارەدانێکی بچووکی ڕاستەقینە تاقی بکەرەوە.

## تێبینیی ئاسایش

چوونەژوورەوە تەنها بە ژمارەی مۆبایل و بێ کۆد بڕیاری خاوەنی ئەپ بوو. بەڵام هەر کەسێک ژمارەی کەسێکی تر بزانێت دەتوانێت بچێتە ناو هەژمارەکەی. سیستەمەکە ئەم مەترسییە کەم دەکاتەوە:
- ژمارەی هەوڵەکانی چوونەژوورەوە سنووردارە.
- هەژماری مۆبایل هەرگیز نابێتە بەڕێوەبەر و دەستی بە تۆمارەکانی پارە ناگات.
- بەکارهێنەری بلۆککراو ناتوانێت بچێتە ژوورەوە.

دواتر دەتوانیت PINی ٤ ژمارەیی یان کۆدی SMS زیاد بکەیت.

**دەقەکان:** هەموو دەقەکانی ئەپ لە `app/js/i18n.js`ن، و دەقی ئاگادارکردنەوەکان لە `functions/src/messages.js`. پێش بڵاوکردنەوە، با کەسێکی زمانزان دەقە کوردی و عەرەبییەکان بپشکنێت، بە تایبەتی بادینی.
